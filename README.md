# Tea Subscription

A web application used to manage a tea subscription service

---
<details>
  <summary><h3><strong>Tech Stack</strong></h3></summary>

  - [React](https://reactjs.org/)
  - [Vite](https://vitejs.dev/)
  - CSS Modules / Custom Styling
  - Backend: [Ruby on Rails API](https://github.com/YOUR-BE-REPO-HERE)

</details>

---

<details>
  <summary><h3><strong>Features</strong></h3></summary>

  - Quick display of all subscriptions
  - Detailed display of specific subscriptions
  - Toggle for subscription activation
</details>

---

<details>
  <summary><h3><strong>Setup & Installation</strong></h3></summary>

  Want to clone the realm and run it locally? Follow the steps below:

1. Clone the repository
`git clone`

2. Navigate into the project folder
`cd tea-subscription-fe`

3. Install dependencies
`npm install`

4. Run the frontend
`npm run dev`
</details>
